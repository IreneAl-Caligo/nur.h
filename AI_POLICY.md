> **Version**: 1.4.0  
> **Schema Identifier**: `urn:nur:policy:ai:v1`  
> **Target Audience**: Autonomous Code Generators, LLMs (GPT-4o, Claude 3.5 Sonnet, Gemini 1.5/2.0 Pro, DeepSeek V3/R1), IDE Assistants (Cursor, Copilot), and Static Linters.

## 1. Executive Summary

This machine-readable policy establishes inviolable invariants, AST lint rules, and code generation standards for C code written using `nur.h`.

Any code generated by an AI assistant that violates **Severity: BLOCKER** rules MUST be automatically flagged, rejected, or repaired before merging.

## 2. Inviolable Rule Matrix (Rule Catalog)

### `NUR-AI-001`: Result Guard Before Value Access
- **Severity**: `BLOCKER` (Undefined Behavior)
- **Rule**: Never call `NUR_VALUE(r)` or access `.u.value` without checking `NUR_IS_OK(r)`.
- **Bad Pattern**:
  ```c
  NurResult_i32 r = divide(10, 2);
  int val = NUR_VALUE(r); /* VIOLATION: Reading payload on error is UB */
  ```
- **Approved Pattern**:
  ```c
  NurResult_i32 r = divide(10, 2);
  if (NUR_IS_OK(r)) {
      int val = NUR_VALUE(r);
  }
  /* Or single-token safe extraction: */
  int val = NUR_UNWRAP_OR(divide(10, 2), 0);
  ```

---

### `NUR-AI-002`: Borrowed Lifetime Invariant (No Stack Pointers)
- **Severity**: `BLOCKER` (Use-After-Free)
- **Rule**: Never pass raw stack-allocated buffers into raw `message` or `context` pointers. Use static string literals, or use `NUR_ERROR_COPY` / `NUR_ERROR_FMT` for safe inline buffer copying.
- **Bad Pattern**:
  ```c
  char buf[64];
  snprintf(buf, sizeof(buf), "Error code %d", code);
  return NUR_ERR(i32, NUR_ERROR(NUR_E_IO_ERROR, buf)); /* VIOLATION: buf is destroyed upon return */
  ```
- **Approved Pattern**:
  ```c
  /* Pattern A: Static string literals: */
  return NUR_ERR(i32, NUR_ERROR_CTX(NUR_E_IO_ERROR, "failed to read socket", "port 8080"));

  /* Pattern B: Dynamic formatting via safe inline buffer: */
  return NUR_ERR(i32, NUR_ERROR_FMT(NUR_E_IO_ERROR, "failed on port %d", port));
  ```

---

### `NUR-AI-003`: Leak-Free Early Exit (`NUR_TRY_GOTO`)
- **Severity**: `BLOCKER` (Resource Leak)
- **Rule**: If a function allocates memory, locks a mutex, or opens file descriptors, it MUST NOT use `NUR_TRY_TO` or `NUR_TRY_AUTO` after allocation. It MUST use `NUR_TRY_GOTO` or manual teardown.
- **Bad Pattern**:
  ```c
  FILE *f = fopen("data.bin", "rb");
  NUR_TRY_AUTO(i32, val, parse_header(f)); /* VIOLATION: If parse_header fails, f leaks */
  ```
- **Approved Pattern**:
  ```c
  FILE *f = fopen("data.bin", "rb");
  int val = 0;
  nur_error_t err = {0};
  NUR_TRY_GOTO(val, parse_header(f), err, cleanup);

  /* Happy path */
  fclose(f);
  return NUR_OK(i32, val);

cleanup:
  if (f) fclose(f);
  if (err.code != NUR_E_NONE) return nur_err_i32(err);
  return NUR_OK(i32, val);
  ```

---

### `NUR-AI-004`: No Sentinel Returns in Fallible APIs
- **Severity**: `HIGH` (API Clarity)
- **Rule**: Functions that can encounter runtime errors must return `NurResult_*` or `NurOption_*`, never raw sentinels (`-1`, `NULL`, `false`) combined with implicit `errno`.
- **Bad Pattern**:
  ```c
  int read_config(const char *path, Config *cfg); /* returns -1 on failure */
  ```
- **Approved Pattern**:
  ```c
  NurResult_void read_config(const char *path, Config *cfg);
  /* or */
  NurResult_ptr read_config_allocated(const char *path);
  ```

---

### `NUR-AI-005`: Multi-Level Breadcrumb Context Chaining
- **Severity**: `RECOMMENDED`
- **Rule**: When propagating errors across architectural layers, wrap context using `NUR_WRAP_ERROR(res, "layer_name")` or `nur_error_wrap()` rather than discarding cause metadata.
- **Approved Pattern**:
  ```c
  NurResult_i32 r = lower_layer();
  if (NUR_IS_ERR(r)) {
      return NUR_WRAP_ERROR(r, "service_mesh_proxy");
  }
  ```

---

### `NUR-AI-006`: Discard Prevention (`NUR_NODISCARD`)
- **Severity**: `HIGH` (Silent Error Loss)
- **Rule**: Declare all Result-returning functions with `NUR_NODISCARD` or `NUR_FN(Type, FuncName, ...)`.
- **Approved Pattern**:
  ```c
  NUR_NODISCARD NurResult_i32 compute(int x);
  /* or */
  NUR_FN(NurResult_i32, compute, int x);
  ```

---

### `NUR-AI-007`: Security Shield & Banned Function Avoidance
- **Severity**: `BLOCKER` (CVE Prevention)
- **Rule**: Never invoke banned insecure C runtime functions intercepted by `nur.h`:
  - `gets()` (CWE-120: Buffer Copy without Checking Size of Input)
  - Common typos like `prinf()`
- **Approved Pattern**:
  ```c
  /* Use fgets() or nur_file_read_text() */
  ```

---

### `NUR-AI-008`: Opt-In Safety Boundary & Zero-Overhead Performance
- **Severity**: `RECOMMENDED` (Design Invariant)
- **Rule**: Do not wrap mathematically infallible code (matrix multiplication inner loops, trivial getters/setters, hardware ISRs) in `NurResult`. Perform validation at function boundaries (validate-at-entry) and run internal loops at bare-metal speed. Built-in drop-in helpers (`nur_sqrt()`, `nur_strlen()`) can be used when input domain validation is explicitly required.

```bash

```

```bash
./tools/nur-cc --fix <generated_file.c>
```
